01 · Overview

What is TermuxVoid?

TermuxVoid is an unofficial custom repository for Termux. It provides extra tools that are not in the official repos, or are excluded from them: ethical hacking, bug bounty, cyber security, reverse engineering, and Android utilities.

The same packages ship as both an APT (dpkg) and a Pacman repository. They are compiled natively for Android, so pkg install works on either setup.

Every tool on this page is read live from the repository index. Nothing is hard-coded and nothing is out of date.

03 · Setup

Add the repository

Pick the setup that matches your Termux install, then install any tool with pkg install.

APT / dpkg setupCMD.01
curl -fsSL https://v.gd/termuxvoid_apt | bash
Pacman setupCMD.02
curl -fsSL https://v.gd/termuxvoid_pacman | bash
Install any toolCMD.03
pkg install <tool-name>
ExampleCMD.04
pkg install metasploit-framework

On a full Pacman setup you can also use pacman -S <tool-name>. Sources: APT repo · Pacman repo

04 · Notes

Registry notes & FAQ

Are these tools legal to use?

All tools are for legal security research and ethical hacking only. Always get permission before testing systems you do not own.

How often are tools updated?
  • Security patches within 24 hours
  • Version updates every Sunday
  • Emergency fixes as needed
Can I request a new tool?

Yes. Use GitHub Issues, Telegram, or email:

  • GitHub Issues
  • Telegram @termuxvoid
  • Email termuxvoid@gmail.com
How do I report a broken package?

Open an issue on GitHub with the tool name and the error output. We aim to fix reported issues within 24 hours.
